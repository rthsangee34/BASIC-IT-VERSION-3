The Digital Foundation

A Number System is a mathematical way to represent numbers using specific digits or symbols.

Binary System

Uses only 2 digits: 0 and 1. The native language of all computers.

Decimal System

Uses 10 digits: 0-9. The standard system used by humans in everyday life.

Octal System

Uses 8 digits: 0-7. Often used in computing as a shorter way of representing binary.

Hexadecimal

Uses 16 symbols: 0-9 and A-F. Extremely efficient for memory addresses.

Understanding the structure and base (radix) of each system.

Key Terminology

Fundamental concepts you need to know.

Base (Radix)

The total number of unique digits used in the system.

Digit

A single symbol used in a number system. E.g., '5' in 345.

MSB

Most Significant Bit: The leftmost digit with the highest value.

LSB

Least Significant Bit: The rightmost digit with the lowest value.

Number Conversions

Step-by-step methods to switch between different bases.

Decimal → Binary

1

Repeated Division

Divide the decimal number by 2 and record the remainder.

2

Record Remainder

Continue dividing the quotient until it becomes 0.

3

Read Bottom-Up

The binary answer is the remainders read from last to first.

Example (10 to Binary):
10 ÷ 2 = 5 (R: 0)
5 ÷ 2 = 2 (R: 1)
2 ÷ 2 = 1 (R: 0)
1 ÷ 2 = 0 (R: 1)
Result: (1010)₂

Binary → Decimal

1

Assign Weights

Start from the right (LSB) and assign powers of 2 (2⁰, 2¹, 2²...).

2

Multiply

Multiply each bit by its assigned power of 2.

3

Sum Up

Add all the results to get the decimal value.

Example (1011)₂:
(1 × 2³) + (0 × 2²) + (1 × 2¹) + (1 × 2⁰)
8 + 0 + 2 + 1 = 11₁₀
